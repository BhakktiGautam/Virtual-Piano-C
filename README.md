🎹 Virtual Piano in C

A console-based multi-octave virtual piano built in C that allows users to play musical notes using keyboard keys in real time. This project simulates a simple piano experience by mapping keyboard inputs to sound frequencies using the Windows Beep() function.

🚀 Features
🎼 Real-time keyboard input using getch()
🎹 Normal octave support
🎵 Lower octave support
🔊 Sound generation with Beep()
🖥️ Console-based piano layout
⌨️ Uppercase and lowercase key compatibility
❌ Quit option for graceful exit
